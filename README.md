# Web Sitesi Kurulum

Web sitesi geliştirme için aşamalı Codex çalışma paketi.

## Paketi indir

[Çalışma paketini ZIP olarak indir](web-sitesi-calisma-paketi.zip?raw=true)

ZIP dosyasını açın ve içindeki BASLA.md dosyasından başlayın. Kuralları mevcut web sitesi projenize yerleştirin. Bu repo web sitesi kaynak kodunu içermez.

## İçerik

- Altı aşamalı geliştirme ve teslim süreci
- Kısa AGENTS.md ve ihtiyaca göre okunan aşama belgeleri
- Önce/sonra görüntüleriyle değişiklik kontrolü
- Animasyon planı ve hareket azaltma desteği
- Müşteriden istenecek bilgiler ve teslim kontrol listesi

Paket Toprak Ehli örneği için hazırlanmıştır. Başka projede kullanırken proje adını, referans adresini ve kapsamı güncelleyin.
